# Primary resources

A small reference set; these projects are linked, not vendored or presented as original work.

| Resource | Use |
| --- | --- |
| [SpiderFoot](https://github.com/smicallef/spiderfoot) | Study modular OSINT collection and correlation |
| [OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/) | Structure web security labs and assessment methods |
| [OWASP Mobile Application Security](https://mas.owasp.org/) | Mobile testing methods and reference material |
| [Nuclei templates](https://github.com/projectdiscovery/nuclei-templates) | Study detection templates and contribution requirements |
| [MITRE ATT&CK](https://attack.mitre.org/) | Map observed behaviors to documented techniques |
| [GitHub repository security](https://docs.github.com/en/code-security/getting-started/quickstart-for-securing-your-repository) | Secret protection, dependency alerts, and code scanning |

## Repository settings

The included workflow runs offline tests. A workflow file does not enable account-level security settings. Separately review secret scanning and push protection, dependency alerts, and CodeQL availability in repository settings. Do not claim these are enabled until their actual settings are verified.
