# Security policy

## Reporting a vulnerability

Use this repository's GitHub **Security → Report a vulnerability** form when private vulnerability reporting is enabled. Include the affected commit, minimal reproduction steps, expected versus actual behavior, and impact. Omit credentials and unrelated personal data.

If the private form is unavailable, open an issue requesting a private reporting channel without including exploitable details. Ordinary bugs and documentation corrections can use public issues and pull requests.

## Scope

This policy covers this repository's original utilities and lab configuration. Report issues in third-party tools directly to their upstream maintainers. A catalog listing is not a security endorsement or maintenance commitment for that project.

Reports should target the current default branch. No response deadline or bounty is promised. See [CONTRIBUTING.md](CONTRIBUTING.md) for research and publication guidance.
